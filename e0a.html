Question · Frozen confirmation

Can a message reveal something the decision-maker cannot otherwise know?

Four checks · Frozen confirmation

Four different checks

Information can arrive without affecting a decision. These checks separate hiddenness, transmission, causal use and the disappearance of added value.

  1. A1 Is something useful actually hidden?
  2. A2 Does the message add information?
  3. A3 Does the consumer use it?
  4. A4 Does its added benefit shrink when the answer becomes public?

Hold the task fixed. Replace only the message.

Genuine replacement

Same target, public context and consumer. A message associated with the alternative private state changes the decision.

Eligible population: 50%. Expected reward drop within that eligible portion: 1.

Sham comparison · illustration

Same target, public context and consumer. Reinsert the original message: nothing relevant has been replaced. This distinguishes replacement from the handling procedure.

The eligible reward drop is not a loss across the whole task population.

Why 500?

The registered plan allocates family error 5% across an exact binomial reliability interval and separate bounds on the endpoint declines. The observed-benefit bound allows the full registered range and does not assume optimal training.

Under ideal outcomes in this plan, 395 is the minimum calculated sample size for the observed-benefit lower bound to reach its threshold. The registered 500 adds margin. This is not an intrinsic requirement of E0-A or a power guarantee. More seeds also give the all-seed guard more opportunities to detect a failure.

How it was measured

Two-sided Hoeffding radius = range width × sqrt(log(2 / allocated alpha) / (2 × seed count)). The extraction script recomputes each radius against the archived adjudication. The calculation does not revise the completed test.
